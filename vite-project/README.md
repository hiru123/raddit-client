# Reddit Client

## Overview
A Reddit browsing application built with React and Redux. Users can view posts, search posts, filter by subreddit, and open a detailed view with comments.

## Technologies Used
- React
- Redux Toolkit
- Vite
- CSS / Responsive Design
- Jest (unit tests)
- Selenium / Cypress (end-to-end tests)
- Git & GitHub
- Reddit API

## Features
- View Reddit posts
- Search posts by keyword
- Filter posts by predefined subreddits
- View comments in a detailed modal/page
- Responsive design (mobile → desktop)
- Smooth animations and transitions
- Error handling and recovery
- High Lighthouse scores
